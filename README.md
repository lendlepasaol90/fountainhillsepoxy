# Fountain Hills Epoxy

Static website for fountainhillsepoxy.com: epoxy and concrete floor coatings in Fountain Hills, AZ.

Plain HTML/CSS/JS with no build step. Deploy the repository root as-is to any static host (Cloudflare Pages, Netlify, Vercel, GitHub Pages).

- `index.html` homepage
- `<service>-fountain-hills-az/index.html` nine service pages
- `assets/` logo, favicons and photos
- `sitemap.xml`, `robots.txt`

Before launch: replace the placeholder phone number (480) 555-0148 and confirm info@fountainhillsepoxy.com. The estimate forms are front-end only and are not yet connected to an inbox.
